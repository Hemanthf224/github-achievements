# 🏆 GitHub Achievements Tracker

A repository documenting and tracking GitHub profile achievements, requirements, and milestones.

## 🎯 Targeted Solo Achievements

| Badge | Name | Requirement | Status |
| :---: | :--- | :--- | :---: |
| 🤠 | **Quickdraw** | Close an issue or PR within 5 minutes of opening | ✅ Completed |
| 🟡 | **YOLO** | Merge a pull request without code review | 🔄 In Progress |
| 🦈 | **Pull Shark** | Have 2 pull requests merged into default branch | 🔄 In Progress |

---

## 📖 Achievement Details

### 🤠 Quickdraw
- **Trigger**: Closed Issue #1 within 5 minutes of creation on the public repository.
- **Badge Tier**: Unlocked (Single tier).

### 🟡 YOLO
- **Trigger**: Merging a Pull Request without requesting or requiring reviews.
- **Badge Tier**: Unlocked (Single tier).

### 🦈 Pull Shark
- **Trigger**: Successfully opening and merging 2 Pull Requests.
- **Badge Tiers**:
  - Default: 2 Merged PRs
  - Bronze: 16 Merged PRs
  - Silver: 128 Merged PRs
  - Gold: 1,024 Merged PRs
