# 🏆 GitHub Achievements Tracker

A repository documenting and tracking GitHub profile achievements, requirements, and milestones.

## 🎯 Targeted Solo Achievements

| Badge | Name | Requirement | Status |
| :---: | :--- | :--- | :---: |
| 🤠 | **Quickdraw** | Close an issue or PR within 5 minutes of opening | ✅ Completed |
| 🟡 | **YOLO** | Merge a pull request without code review | ✅ Completed |
| 🦈 | **Pull Shark** | Have 2 pull requests merged into default branch | ✅ Completed |

---

## 📖 Achievement Details

### 🤠 Quickdraw
- **Trigger**: Closed Issue #1 within seconds of creation on a public repository.
- **Badge Tier**: Unlocked (Single tier).

### 🟡 YOLO
- **Trigger**: Merged Pull Request #2 without code review on the default branch.
- **Badge Tier**: Unlocked (Single tier).

### 🦈 Pull Shark
- **Trigger**: Successfully merged 2 Pull Requests (#2 and #3) into the repository's default branch.
- **Badge Tiers**:
  - Default: 2 Merged PRs (Unlocked)
  - Bronze: 16 Merged PRs
  - Silver: 128 Merged PRs
  - Gold: 1,024 Merged PRs
