## 📖 Achievement Details

### 🤠 Quickdraw
- **Trigger**: Closed [Issue #1](https://github.com/Hemanthf224/github-achievements/issues/1) within ~15 seconds of creation.
- **Badge Tier**: Single tier.

### 🟡 YOLO
- **Trigger**: Merged [Pull Request #2](https://github.com/Hemanthf224/github-achievements/pull/2) directly into `main` without requiring code review.
- **Badge Tier**: Single tier.

### 🦈 Pull Shark
- **Trigger**: Merged multiple pull requests into the default branch.
- **Tiers**:
  - Default: 2 Merged PRs (Achieved!)
  - Bronze: 16 Merged PRs
  - Silver: 128 Merged PRs
  - Gold: 1,024 Merged PRs

### 👯 Pair Extraordinaire
- **Trigger**: Merged a pull request with co-authored commit trailer metadata:
  ```text
  Co-authored-by: Kaushal Reddy <84959787+kaushalrog@users.noreply.github.com>
  ```
- **Tiers**:
  - Default: 1 Co-authored PR (Achieved!)
  - Bronze: 10 Co-authored PRs
  - Silver: 24 Co-authored PRs
  - Gold: 48 Co-authored PRs
