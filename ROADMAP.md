# 🗺️ GitHub Achievements Roadmap

This document outlines all current and legacy GitHub achievements, their tier requirements, and unlocking strategies.

| Achievement | Requirement | Tiers | Status |
| :--- | :--- | :--- | :--- |
| **🤠 Quickdraw** | Close issue/PR within 5m | Default (1) | ✅ Unlocked |
| **🟡 YOLO** | Merge PR without review | Default (1) | ✅ Unlocked |
| **🦈 Pull Shark** | Merge Pull Requests | 2, 16, 128, 1024 | 🚀 Tier 1 Unlocked (Progressing to Bronze) |
| **👯 Pair Extraordinaire** | Co-authored merged PRs | 1, 10, 24, 48 | 🚀 Unlocked (Progressing to Bronze) |
| **🧠 Galaxy Brain** | Answer Q&A in Discussions | 2, 8, 16, 32 | ⏳ Community / Peer Q&A |
| **🌟 Starstruck** | Stars on your repository | 16, 128, 512, 4096 | ⏳ Peer Stars |
| **💖 Public Sponsor** | Sponsor via GitHub Sponsors | Default (1) | 💳 $1 Sponsorship |
